# Diplomatik Buzdolabı Müzakeresi

> **Uluslararası Artık Yemek Hukuku Enstitüsü** resmi referans uygulaması.

Bu yazılım, evinizdeki buzdolabının içindeki yoğurt, dün akşamdan kalan köfte ve “bunu yarın yerim” diye üç haftadır duran çorbanın **egemenlik haklarını** tanır. Her kapak açılışı bir sınır ihlali, her “bu hâlâ yenir mi?” sorusu bir diplomatik krizdir.

## Neden var?

Çünkü insanlık uzaya çıktı ama evdeki kaşarın son kullanma tarihini hâlâ gözle tahmin ediyor. Bu kabul edilemez bir medeniyet skandalıdır.

## Kuruluş

```bash
python3 muzakere.py
```

Bağımlılık yok. Sadece Python 3 ve vicdan.

## Protokol

Program sizi Dışişleri Bakanlığı mutfak masasına oturtur. Buzdolabı temsilcisi (yazılım) üç madde sunar:

1. Tanınma
2. Ateşkes (kapağı kapat)
3. İnsani koridor (çürüyen ürünlerin tahliyesi)

Kararınız kayda geçer. Kayıtlar tarihsel belge niteliğindedir. İleride arkeologlar bunlarla doktora yazacak.
